# Исследование и параметрический анализ архитектуры контрастивного самообучения временных рядов TS-TCC

Репозиторий содержит материалы технологической практики по большим данным и интеллектуальным системам.

В основе проекта лежит репликация и параметрический анализ модели из статьи CORE A*:
> **Eldele et al.** Time-Series Representation Learning via Temporal and Contextual Contrasting (IJCAI 2021).

## Воспроизводимость и Окружение
Эксперименты реализованы в среде Google Colab с использованием GPU NVIDIA T4.
* **Стек:** Python 3.12.11, PyTorch 2.11.0, NumPy, Scikit-learn.
* **Детерминированность:** Для строгого воспроизведения результатов во всех скриптах зафиксирован единый seed = 030203

## Используемые метрики качества
Оценка эффективности извлечения признаков проводилась в режимах `supervised`, `train_linear`, `fine_tune` по метрикам:
1. **Accuracy (Точность классификации)**
2. **Macro F1-Score (Усредненная F-мера)**

## Структура проекта
* `/config_files/` — конфигурационные файлы гиперпараметров.
* `/dataloader/augmentations.py` — Модуль стохастической аугментации данных. Было внесено изменение для возможности детерменированности экспериментов.
* `TS-TCC Exp.ipynb` — основной рабочий ноутбук (репликация + 27 экспериментов).
* `requirements.txt` — список зависимостей.

## Запуск экспериментов

1. Откройте файл `TS-TCC Exp.ipynb` в среде Google Colab.
2. Подключите GPU-акселератор T4 и Google Drive Disk.
3. Выполните все ячейки по порядку до экспериментов (пайплайн автоматически скачает данные и запустит эксперименты).
4. Далее меняйте гиперпараметры через `config_files/Epilepsy_Configs.py`
5. Запускайте эксперименты с соответствующими настройками
